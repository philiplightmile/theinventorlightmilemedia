# Cleveland Film: Contact Rules
- Record an email only if printed on a page the script fetched. Never infer or pattern-build.
- Respect robots.txt. Blocked site = site_failed.
- Follow only links containing contact, grants, programs, apply, guidelines, about. No staff directory links.
- Prefer a grants/program inbox over a named person. A named program officer is usable only if printed with a role on a fetched page. Never default to a CEO or executive director.
- Skip wrong-channel roles (press, media, HR, careers, webmaster). List skipped.
- No personal addresses (Gmail, Yahoo). Flag if a tool returns one.
- Many funders ask applicants to call or use a portal first. If so, record status "use_portal" with the URL and do not draft an email.
- Save after every organization. Columns: Organization | Email | Source page URL | Tag (on_unit_page/other_page) | Status (ok/site_failed/no_email/phone_only/use_portal)
